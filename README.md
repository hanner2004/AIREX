
# AIREX - Sistema de mantenimiento de aires acondicionados

## Descripción
AIREX es una aplicación desarrollada en Python que permite registrar equipos de aire acondicionado y llevar un control de sus mantenimientos.

## Objetivo
Facilitar el registro y la consulta de equipos y mantenimientos realizados.

## Funcionalidades
- Registrar aires acondicionados.
- Consultar equipos registrados.
- Registrar mantenimientos.
- Consultar el historial de mantenimientos.

## Tecnologías utilizadas
- Python.
- Tkinter para la interfaz gráfica.
- Programación Orientada a Objetos (POO).

## Estructura del proyecto
- main.py: inicia el programa.
- equipo.py: contiene las clases de los equipos.
- mantenimiento.py: contiene la clase de mantenimiento.
- interfaz.py: contiene la interfaz gráfica.
- docs/: contiene el informe técnico.

## Ejecución
1. Tener Python instalado.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo main.py.
